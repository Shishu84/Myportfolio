# 🌐 Portfolio Website

Welcome to my personal portfolio website!  
This project showcases my work, skills, and projects in a clean and responsive design.

---

## 🚀 Features
- **Responsive Design** – Works seamlessly across desktop, tablet, and mobile.
- **Project Showcase** – Highlights my key projects with descriptions and links.
- **About Me Section** – Introduces my background, skills, and interests.
- **Contact Form** – Easy way for visitors to get in touch.
- **Dark Mode** – Modern UI with light/dark theme support.

- **Styling:** Tailwind CSS 
- **Deployment:** GitHub Pages
